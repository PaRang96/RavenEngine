RavenEngine Windows x64 player preview

Keep this folder together and open RavenEngine.exe. The first packaged
level opens automatically. F4 switches between packaged levels and F3
restarts the current level. Use WASD to move, Q/E to change height,
right-drag to look, and left-click to interact.

This build uses the bundled content and a writable folder for its
game DLL execution copy. You can move the whole folder to another
location on a supported Windows x64 machine.

Runtime prerequisites

- A Vulkan-capable graphics driver with the x64 Vulkan loader.
- The x64 Microsoft Visual C++ Redistributable for the MSVC toolset
  that built the player.
- Windows XAudio2 2.9 for audio playback.

Licenses for bundled third-party components are in Licenses/.
